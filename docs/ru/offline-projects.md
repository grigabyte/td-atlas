# Чтение проектов офлайн

В поставке TouchDesigner есть `toeexpand`, который распаковывает `.toe`/`.tox`
в дерево текстовых файлов. td-atlas читает это дерево, поэтому проект можно
рассмотреть, обыскать и сравнить **с закрытым TouchDesigner**. Всё происходит
на копии в кеше, а оригинал никто не трогает.

@@kod:1@@

`grep` достаёт код, до которого не дотянется никакой поиск по файлам. Python
и GLSL внутри DAT лежат в контейнере, на диске их нет.

`diff` сравнивает смысл. Он перечисляет операторы, которые добавили, убрали,
которым сменили тип, которые перевязали и которым поменяли параметры, плюс
построчный diff изменённого кода DAT. Узлы, которые только переставили, идут
отдельно, и настоящую правку они собой не закроют. Вместе с `td_snapshot`
сравнение даёт след правок агента, который можно проверить.

Форматы файлов нигде не описаны, и читатели их выведены замером. Пролог
полезной нагрузки занимает ровно 27 байт с полем длины, и поиск перевода
строки портит примерно каждый третий шейдер. Бит 4 в слове флагов параметра
означает режим выражения. Псевдонимов сохранённых имён 71, и получены они так.
Каждый тип создали, а потом сверили написание в файле с типом, который
TouchDesigner для него называет.
