# Индекс атомов

Два прохода дают один индекс SQLite, точный для той сборки, с которой его
сняли.

**Офлайновый проход.** Без процесса TouchDesigner, 13–16 секунд за три прогона,
замерено 2026-09-12 на Mac с процессором серии M и сборке 2025.32460:

| Что читается в бандле программы | Что оттуда получается |
| --- | --- |
| `Config/TDParameterHelp.json` | каждый оператор и каждый параметр: подписи, описания, типы |
| `Samples/Learn/OfflineHelp/` | офлайновая вики: классы Python, страницы операторов, статьи словаря, статьи про понятия и приёмы |
| `Samples/Palette/` | **готовые компоненты**: проекционный маппинг, подтяжка углов, разбор звука |
| `Samples/Learn/OPSnippets/` | работающие сети-примеры, по одной на оператор |
| `Config/Help/{command.help,exprhelp}` | статьи про команды и выражения |

**Проход по запущенной программе.** Создаёт по одному оператору каждого типа
в песочнице без готовки и читает то, чего документация не записывает. Значения
по умолчанию, числовые диапазоны и ограничители, **пункты меню**, страницы
параметров и их порядок, число разъёмов и сокращённые имена типов, которые
TouchDesigner пишет при сохранении. Готовка в песочнице выключена. Video
Device In TOP, которому дали свариться, включает камеру.

Два прохода в сумме не сходятся, и причина во втором. Он находит типы
операторов, которых нет в справочном JSON, и тысячи параметров, которых там
нет в списке. Чаще всего это те, чьи значения по умолчанию и пункты меню
узнаются только вопросом к запущенной копии.

**Счётчики принадлежат вашей сборке.** Запустите `td-atlas status`, и он
напечатает, сколько операторов, параметров и статей вики лежит в вашем
индексе на самом деле. Главной проект считает именно эту строку. Для масштаба:
на сборке 2025.32460 под macOS там стоит `667 ops, 24251 params, 2060 articles`.
