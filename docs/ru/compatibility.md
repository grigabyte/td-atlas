# Совместимость

**TouchDesigner.** Всё здесь промерено на сборке **2025.32460**. Индекс
читается из того каталога программы, на который вы указали, поэтому другая
сборка даёт другой индекс. Если TouchDesigner переставили, обновили или
заменили, соберите индекс заново командой `td-atlas build`; `td-atlas doctor`
заметит, когда этого ещё не сделали. Мост и хост сходятся на версии протокола
и отказывают друг другу при расхождении, называя сторону, которая отстала.

**Python.** 3.11 или новее на хосте. Код, который работает *внутри*
TouchDesigner, держится на 3.11 и без сторонних импортов, потому что такой
интерпретатор идёт в поставке программы.

**Операционные системы.**

| | |
| --- | --- |
| macOS | здесь разрабатывали и мерили; каждое число снято на нём |
| Windows | ветки кода гоняются в CI (`windows-latest`, Python 3.11-3.14, первый прогон 2026-09-07); **TouchDesigner на Windows не проверен**: машины с Windows и TouchDesigner на ней в работе не было ни разу |
| Linux | не поддерживается: TouchDesigner под него не выпускают |

Три вещи на Windows остаются непроверенными. Поиск установки идёт по тому
дереву каталогов, которое Derivative опубликовала, и на месте это никто
не мерил. Разделители пути у `toeexpand` выведены из его вывода на macOS.
Копию в буфер обмена (`clip`) не запускали ни разу.

Две вещи там теперь *известны* и слабее. Права на `~/.td-atlas` и на файл
токена внутри сужаются через `chmod`, а `chmod` на Windows ставит только
атрибут «только для чтения». По замеру каталог показывает режим 0o777 там, где
просили 0o700, и чужие учётные записи держит снаружи тот ACL, который уже несёт
профиль пользователя. Ещё журнал вызовов не умеет сообщить про домашний
каталог, который отказывает в записи, потому что `os.access` этого отказа там
не видит.

Закрытый порт на петле в Windows отказывает примерно за **две секунды**, против
0.04 мс на macOS, поэтому проба теперь ждёт 3 с на обеих системах. Примерно
столько стоит каждая мёртвая запись, когда `td-atlas instances` её вычищает.
Число и его цена записаны у `PROBE_BUDGET` в `config.py`.

Проверки, для которых на Windows нет посылки, пропускаются с этой причиной,
выписанной прямо в `tests/windows_gaps.py`. `os.chmod` там не умеет ни сузить
режим, ни заставить путь отказать в доступе.

Зелёная колонка Windows в CI (`.github/workflows/ci.yml`) значит, что ветки
кода для Windows отработали и их модульные тесты прошли. Про TouchDesigner
на Windows она не говорит ничего. У раннера GitHub нет TouchDesigner и быть
не может, поэтому всё, что ищет установку или зовёт `toeexpand`, там
пропускается.

**Что это может изменить в вашем проекте.** Стоит прочитать до того, как
наводить агента на работу, которая вам дорога.

- **Мост живёт компонентом внутри вашего открытого проекта.** Строка bootstrap
  строит `/tdatlas` в открытом проекте: Web Server DAT, DAT с обратными
  вызовами и панель состояния. Повторный запуск строки обновляет эти узлы
  на месте. Это такой же узел вашей сети, как остальные, и он сохраняется
  вместе с проектом, когда вы проект сохраняете.
- **Правки настоящие.** `td_build`, `td_set_params`, `td_set_flags`,
  `td_annotate`, `td_extension_add`, `td_palette_load` и `td_exec` меняют живую
  сеть. `td_build` заворачивает пачку в один блок `ui.undo`, поэтому она
  отменяется одним **Ctrl+Z**, а сорвавшаяся пачка откатывается сама.
  `td_exec` выполняет произвольный Python, и такой гарантии он не даёт.
- **Ваш проект никто не сохраняет.** `project.save()` не зовёт ни один
  инструмент. `td_snapshot` пишет *компонент* в `~/.td-atlas/snapshots`.
  Сохранение сессии было бы Save As, и работать вы после него продолжали бы
  внутри `~/.td-atlas`.
- **Запись текста рядом с `.toe` по умолчанию выключена**, её включает
  `"text_on_save": true` в `~/.td-atlas/config.json`. Чужой файл с таким
  именем никогда не переписывается.
- **Чтение проекта его не трогает.** `toeexpand` и `toecollapse` работают
  на месте, и `toecollapse` переименовывает оригинал в `<name>.bkp1`, поэтому
  любое чтение офлайн сперва копирует файл в кеш под
  `~/.td-atlas/cache`. Запись (`td_project_write`, `td_variant_restore`)
  отказывает, когда выходной путь уже занят.
- **На хосте** td-atlas пишет только под `~/.td-atlas`. Это индекс,
  разложенный мост, журнал вызовов `calls.jsonl` (предел 1 MiB), снимки,
  варианты и кеш распаковок. Кеш ограничен по числу и вытесняет самые давние
  распаковки. `td-atlas doctor` говорит, сколько распаковок в нём лежит,
  а `td-atlas doctor --clear-cache` его чистит.
