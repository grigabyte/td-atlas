# Мост

Web Server DAT и DAT с обратными вызовами, которые строит на месте скрипт.
Мост читается глазами, лежит в системе версий исходным текстом, и правки
в нём видны в diff. Повторный запуск первой строки обновляет мост там, где
он стоит. То же делает `td-atlas reload`, уже через сам мост.

Кроме `exec`:

- **`td_health`**, поиск поломок, о которых программа молчит. Смотрите
  [о чём TouchDesigner молчит](health.md).
- **`render`** отдаёт пиксели любого TOP картинкой PNG, а для всего, что
  меняется во времени, ещё и контактный лист. Судить о стробоскопе по одному
  кадру всё равно что бросать монетку.
- **`batch`** выполняет несколько действий внутри одного блока `ui.undo`.
  Сорвавшаяся пачка откатывается и не оставляет за собой полусети. Удавшаяся
  отменяется одним **Ctrl+Z** художника.
- **`errors`** перечисляет каждый узел, который сообщает об ошибке или
  предупреждении.

По умолчанию запросы проверяются токеном.
