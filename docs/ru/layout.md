# Дерево репозитория

@@kod:1@@

Два вида путей в дерево выше не попали.

**Порождённые, и в git их нет.** `.venv/`, индекс и подготовленный мост
в `~/.td-atlas/`, а также `dist/` с собранным бандлом, `dist/server.json`
и `dist/build.json`. Последний записывает коммит, из которого собран бандл,
поэтому `publish.sh` может отказать устаревшему. `.mcp.json` тоже в игноре.
Его пишет `td-atlas install --write-mcp-json`, и в нём стоит путь, годный
только для вашей машины.

**В игноре, и не порождены ничем.** В `memory-bank/` лежат рабочие записи
владельца. Ничто из дерева выше от них не зависит. Всё, что читателю оттуда
нужно, живёт в `docs/`.
