# Починка

Всё, что похоже на беду с установкой, начинается с `td-atlas doctor`. Он идёт
по цепочке целиком, от окружения через TouchDesigner, индекс, сборку индекса,
проход probe и мост до сервера MCP. У каждого звена, кроме `ok`, рядом стоит
команда починки. Сломанное звено даёт `doctor` ненулевой код возврата.

| Симптом | Что это | Что запустить |
| --- | --- | --- |
| `doctor` говорит `bridge : absent` | ни один TouchDesigner не зарегистрировал мост, и на порту никто не слушает | откройте проект и вставьте в текстпорт строку bootstrap из `td-atlas install` |
| живой инструмент отказывает словами *«nothing answered on the bridge port»* | TouchDesigner не запущен либо запущен без моста | `td-atlas doctor`, потом строка bootstrap |
| *«The running bridge reports protocol N, below the minimum 7 this client supports»*, а из инструмента MCP та же строка плюс подсказка *«the bridge and this host speak different protocol versions»* | разложенный мост старше (или новее) этой копии репозитория. Самый старый мост, который примут, говорит протокол 7; всё, что старше, отвергают прямо на соединении | `td-atlas reload`, единственная команда, которая говорит с мостом, отвергнутым проверкой версии |
| вызов возвращается с `UnknownMethod` | то же самое с другой стороны. Мост разложили из старого пакета, поэтому такого метода у него нет | `td-atlas reload`, потом повторите вызов |
| *«the bridge rejected the token this host sent»* | токен моста и `~/.td-atlas/config.json` расходятся | `td-atlas doctor` их сравнивает; `td-atlas install` раскладывает мост заново под текущий токен |
| *«something answered on that port but not with a bridge reply»* | порт держит другая программа либо Web Server DAT настроен неверно | `td-atlas doctor`, потом `td-atlas install` |
| вызов не дожидается ответа | каждый запрос идёт в главном потоке TouchDesigner во время готовки, поэтому длинный скрипт его затыкает | подождите и повторите мелкими кусками, по одному короткому `td_exec` |
| *«this host has no atom index yet»* | ничего ещё не собирали | `td-atlas build`, потом `td-atlas probe` с открытым TouchDesigner |
| *«the index names a file that is not on disk»* | TouchDesigner переставили, обновили или переустановили после сборки индекса | `td-atlas build`, потом `td-atlas probe` |
| `doctor` говорит, что `index build` расходится | индекс собран с другого TouchDesigner, и инструменты отвечают значениями той, другой сборки | `td-atlas build` |
| ответ про сеть кончается на `TRUNCATED:` либо в нём есть строка `... N more child(ren) not listed` | сеть больше, чем влезает в один ответ. Её обрезал бюджет узлов или предел детей на компонент, и ответ говорит, где именно | спросите снова с более узким `path` |
| в ответе строка `... N direct child(ren), not walked at depth D` | прямо под этим узлом ещё N операторов, и запрошенная глубина кончается над ними. `N` считает только прямых детей, поэтому всё, что висит ниже них, идёт сверх этого числа | спросите снова с большей `depth` или с `path` на этом узле |
| `td_errors` говорит *«the walk stopped after N operator(s) at and under `path`»*, либо `td_health` говорит *«only N operator(s) at and under `path` were sampled»* | обход упёрся в бюджет узлов. Чистый ответ покрывает пройденную часть, и остаток, который каждый из них называет, служит полом | запустите снова по поддереву, через `path` |
| `td_errors` молчит про компонент, который вы только что построили | по умолчанию его `path` указывает на проект. Запрос `/` делает хуже: обход идёт вширь и ограничен, а собственные `/ui` и `/sys` TouchDesigner съедают бюджет раньше, чем очередь дойдёт до вашего | назовите компонент в `path` |
| `td_health` сообщает про ошибки скриптов, которые он *не смог прочитать* | чтение на этой сборке сорвалось, поэтому считайте это место непроверенным | причину называет сам ответ |
| запись отказывает, потому что выходной файл уже есть | `toecollapse` переименовывает то, что нашёл, в `<name>.bkp1`, и поверх ничего не пишется | выберите путь, которого ещё нет |
| `~/.td-atlas/cache` разросся | любое чтение офлайн распаковывает туда копию. Кеш ограничен по числу и вытесняет самые давние распаковки, а старый кеш лежит, пока вы его не опустошите | `td-atlas doctor` говорит, сколько распаковок в нём лежит, `td-atlas doctor --clear-cache` его чистит |
| клиент MCP не может запустить сервер | он зовёт интерпретатор, в котором `td_atlas` не установлен | `td-atlas install` печатает точную строку `claude mcp add`, вместе с абсолютным путём к интерпретатору; звено `mcp server` у `doctor` её проверяет |

`td-atlas log --failures` показывает задним числом, что мост отверг, со
временем каждого отказа. Для агента то же самое делает `td_log`.
