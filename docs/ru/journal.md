# Журнал вызовов

Каждый вызов моста ложится в `~/.td-atlas/calls.jsonl`, по строке на вызов.
Файл переживает сессию, поэтому вчерашние отказы никуда сегодня не делись.

@@kod:1@@

Оба примера обрезаны. `--failures` заканчивает разбором последнего отказа,
строкой `cause:` и строкой `fix:`. `--summary` ещё называет виды отказов
в строке `reasons:` и перечисляет пять самых медленных вызовов.

`td_log` даёт агенту тот же след, и агент может прочитать, на чём уже
отказали, прежде чем звать снова.

Панель состояния внутри TouchDesigner держит *последний* вызов, и следующий
её затирает. Она отвечает на вопрос «жив ли мост». Журнал отвечает на другой
вопрос: «агент вчера что-то сломал, что именно».

Журнал пишет хост. Table DAT внутри TouchDesigner умирает вместе с процессом,
и чтобы такой DAT сохранить, пришлось бы сохранить проект, то есть сделать
Save As и увести файл художника с места.

Файл ограничен 1 МиБ, это примерно 5,300 вызовов по замеру, и самые старые
строки уходят первыми. Параметры в журнал не пишутся. В строке стоят метод,
исход, длительность, путь, кто позвал и число шагов пачки. Текст DAT и целая
сеть в журнал не попадают. Токен моста вычищается из каждой строки до записи.
