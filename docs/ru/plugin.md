# Навык

`plugin/skills/touchdesigner/` держит руководство для агента о работе через
коннектор. Оно называет каждую ловушку, которая не дала ошибки и стоила
настоящего времени:

- ветки, которые уснули;
- операторы на CPU, спрятанные в меню;
- петли обратной связи, которые сходятся в серое;
- аудиокодек, который докладывает об успехе и не пишет файла;
- лицензия, которая вдвое режет разрешение и молчит об этом.

Ставьте навык плагином, тогда обновление займёт одну команду. Репозиторий сам
себе магазин, поэтому в Claude Code:

@@kod:1@@

Дальше `/plugin marketplace update` подтягивает всё, чему навык научился.

Агент, у клиента которого плагинов нет, читает то же руководство прямо
из клона. Наведите его на
[`plugin/skills/touchdesigner/SKILL.md`](../plugin/skills/touchdesigner/SKILL.md),
и не хватать будет только обновления в одну команду.
