# td-atlas

Атомарный индекс TouchDesigner, живой мост в запущенный экземпляр и
офлайн-читатель проектов — для ИИ-агентов через MCP.

## Запуск и сборка

```bash
uv pip install -e . pytest
pytest                  # без TouchDesigner
td-atlas build           # офлайн-индекс
td-atlas probe            # нужен запущенный TouchDesigner с мостом
```
Правка кода — по `AGENTS.md`, это руководство контрибьютора, здесь оно
не пересказывается.

## Инварианты

Измерять, а не угадывать. Тесты не требуют запущенного TouchDesigner.
При выборе между уверенным неверным ответом и честным пробелом —
пробел. Решения, объясняющие форму кода, разобраны там, где стоят:
в комментариях `src/`, в `AGENTS.md` и в `docs/`.

## С чего начать

`docs/architecture.md` (три слоя и почему так) → `docs/cli.md` (все
команды и что каждой нужно) → `AGENTS.md` (руководство контрибьютора).

Рабочая память владельца — каталог `memory-bank/`, он **в git не
входит**: это процесс работы, а не продукт. Есть в рабочем дереве —
начинать с него, порядок чтения записан в его собственном README, и
файлы памяти обновляются в том же цикле, что и работа. Нет — трёх
файлов выше достаточно: канон команд и форматов живёт в `docs/`,
а не в банке.
